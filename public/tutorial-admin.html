🛠️ Туториал для организаторов

4 организатора · 5 команд · 20 студентов · 45–60 минут. Ниже — всё, что нужно знать, чтобы провести игру без сучка и задоринки.

1. Подготовка (до пары, 5 минут)

  1. Ноутбук с Node.js 16+ (nodejs.org). Никаких npm install не нужно.
  2. Запустите: двойной щелчок по start.bat или в терминале node server.js.
  3. В консоли появится адрес: http://localhost:3088 и локальный IP (например, 192.168.1.5). Сообщите студентам: http://192.168.1.5:3088.
  4. Все должны быть в одном Wi-Fi. При первом запуске Windows спросит про доступ Node.js в сеть — нажмите «Разрешить».
  5. Откройте http://localhost:3088/admin.html на ноутбуке. Пароль: admin.
  6. Проверьте вход командой со своего телефона (пароли: A2026, B2026, C2026, D2026, E2026).
  7. Разделите 20 студентов на 5 команд по 4 человека, раздайте роли.
Если студенты не открывают адрес: проверьте Wi-Fi и брандмауэр. Разрешите Node.js доступ к частным сетям.

🎤

🔨

📊

Свод рынка, эластичность, баллы

Админ-панель можно открыть с нескольких устройств под одним паролем admin. Например, ведущий и аукционист сидят с разных ноутбуков.

3. Карта админ-панели

  • Верхняя панель: выбор фазы, таймер (минуты + старт/стоп), объявление-баннер для всех команд.
  • 📊 Команды: карточки с деньгами, ресурсами, статусами. Кнопка «± деньги» для коррекций.
  • 🔨 Аукцион: сцена с текущим лотом, живая лента ставок, склад ресурсов, ручная запись ставок, продажа вне аукциона.
  • 💰 Рынок: кнопка «Свести рынок», таблицы спроса всех команд, калькулятор эталонной эластичности со сверкой ответов команд.
  • 📣 События: пресеты (авария энергосети, налог, рост издержек) и отключение события.
  • ⭐ Баллы: сохранение итоговых баллов по критериям (максимум 60).
  • 🏆 Итоги: рейтинг по капиталу (победитель) и по баллам, подиум с конфетти.
  • 📜 Журнал: все действия с временем — поможет при разборе и выставлении баллов.
  • ♻️ Сброс: полная очистка между группами.

4. Сценарий игры (45–60 минут)

7 минР1 · Анализ спросаЗапустите таймер 7 мин. Команды изучают таблицу спроса. Аналитик отвечает на вопросы.

5 минР3 · ПроизводствоКоманды фиксируют выпуск (потолок — самый дефицитный ресурс, максимум 10).
7 минР4 · РынокКоманды фиксируют цену. Затем нажмите «⚖ Свести рынок» — сервер посчитает спрос, продажи, избыток/дефицит, выручку и прибыль. Обсудите результаты.
7 минР5 · Эластичность спросаОбъявите изменение цены (рекомендуется 300→400 д.е.). Команды считают E и тип. Аналитик: вкладка «Рынок», кнопка «Рассчитать эталон» — сервер покажет правильные коэффициенты и сверит ответы.
5 минР6 · Эластичность предложенияНажмите событие «Подорожали ресурсы» или «Авария на электростанции». Команды считают Es. При необходимости откройте дополнительный лот.
5 минР7 · ИтогиКоманды отправляют отчёты. Аналитик выставляет баллы на вкладке «⭐ Баллы».
5 минНаграждениеВкладка «🏆 Итоги»: объявите победителя по капиталу и лучшие расчёты по баллам. Каждая команда отвечает на вопросы из финального обсуждения.

5. Как проводить аукцион

  1. Вкладка «Аукцион» → выберите ресурс, введите количество лота → «Выставить лот». Стартовые цены: Сырьё 100, Труд 150, Энергия 100 д.е./ед.
  2. Команды делают ставки с телефонов — лента ставок обновляется автоматически (каждые 3 сек).
  3. Дайте командам 30–60 секунд на перебивание ставок, затем «🏁 Закрыть лот»: победитель платит ставка × объём, ресурс зачисляется, склад уменьшается.
  4. Если ставок нет — лот закрывается без продажи, ресурс остаётся на складе.
  5. Если торги идут устно (карточки), запишите ставку кнопкой «Записать ставку» или используйте «Продать вне аукциона».
Рекомендуемый порядок: 3 лота сырья по ~15 ед. → 2–3 лота труда по ~10 ед. → 2–3 лота энергии по ~10 ед. Помните: всего 50 сырья, 30 труда, 30 энергии.

6. Формулы (шпаргалка для организаторов)

Выручка: TR = P × Q

Затраты: TC = Σ (цена ресурса × количество) — сервер считает автоматически.

Прибыль: π = TR − TC − налог (налог × проданное количество).

Итоговый капитал: остаток денег + выручка − налог.

Спрос: продаётся min(выпуск; спрос по таблице). Избыток = выпуск − продано.

Эластичность (метод средней точки):

E = [(Q₂ − Q₁) / ((Q₁+Q₂)/2)] ÷ [(P₂ − P₁) / ((P₁+P₂)/2)]

Кнопка «Рассчитать эталон» на вкладке «Рынок» делает это автоматически и сверяет с ответами команд (допуск 0,06).

Эталон для раунда 5 (300→400): Хлеб/Одежда/Стройматериалы E = −1,40 (эластичный); Мебель/Электроника E = −0,47 (неэластичный). В некоторых методичках указано −1,8 — это ошибка округления. Доверяйте расчёту панели.
Эталон для раунда 6 (P 300→500, Qs 4→8): Es = 1,33 — предложение эластичное.

9. Если что-то пошло не так

  • Команда ошибочно потратила деньги. Банкир: вкладка «Команды» → «± деньги» (можно минус).
  • Ошибка в покупке ресурса. Через «± деньги» верните деньги; ресурсы исправьте продажей «вне аукциона» с ценой 1 д.е. и компенсируйте деньгами.
  • Сервер перезапустился. Состояние сохраняется в файл state.json автоматически — просто запустите сервер снова.
  • Новая группа. Вкладка «♻️ Сброс» → подтвердить.
  • Завис экран команд. Обновление страницы восстанавливает всё: данные живут на сервере.
  • Не открывается на телефоне. Проверьте Wi-Fi и брандмауэр. Разрешите Node.js доступ к частным сетям.

10. Что объяснить после игры

  • Ограниченность ресурсов → произвести всё невозможно, приходится выбирать.
  • Спрос и предложение → дефицит ресурса поднимает цену на аукционе.
  • Альтернативная стоимость → деньги, потраченные на один ресурс, — это отказ от другого.
  • Издержки → влияют на прибыль: дорогие ресурсы съедают выручку.
  • Рыночное равновесие → цена формируется в ходе торгов; избыток и дефицит — сигнал цены.
  • Эластичность → при эластичном спросе повышение цены снижает выручку, при неэластичном — повышает.
